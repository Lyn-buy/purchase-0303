Excel 只在使用者自己的瀏覽器內運算。 5. 上次庫存存在 localStorage。 6. 同一台電腦： A → B = 比較 A / B B → C = 比較 B / C 7. 不同電腦不會共用上一份庫存。 8. 若需要多人共用上一份庫存，需要接 Google Sheets / 資料庫。
